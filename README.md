# 美颜世界：算法研发与产品实践

美颜世界探索地理数据与生成式模型结合的地图艺术化表达。当前产品包括已上线的 **菠萝笔**，以及已完成原型的 **菠萝轨迹**。

[访问菠萝笔](https://www.boluobi.com/) · [常凯尧的个人主页](https://github.com/Changkio)

这是常凯尧的公开项目经历说明，介绍本人承担的工作与产品决策。商业源码、训练资产与具体算法方案不在此仓库公开。

## 角色与分工

**2023 年至今｜联合创始人、算法总监，产品与市场主要负责人**

团队约 9 人，包含算法、前后端开发及美术成员。导师作为核心创始人提出主要项目创意和算法大方向；我与其他算法成员共同推进研发，并承担产品与市场方面的主要工作。

## 算法与开发

- **地理数据与模型训练**：参与公开遥感影像、地图、DEM、GeoJSON 等数据的处理，承担扩散模型修改、训练与微调工作。
- **地图结构正确性**：围绕艺术化生成后地图空间结构是否保持正确开展研发。采用分阶段处理思路，而非直接端到端生成，以控制最终输出中的结构误差。具体实现涉及商业保密。
- **多尺度表达**：参与部分 LOD 算法设计，将课题组已有的传统方法与深度学习结合，探索效率与表达质量的改进。
- **团队协作**：与负责前后端和美术的成员协作，将算法能力接入可供用户使用的产品流程。

## 产品与市场

### 用户与商业模式

| 方向 | 目标用户 | 产品与服务安排 |
| --- | --- | --- |
| B 端 | 文旅公司、景区 | 以定制服务满足具体场景需求 |
| C 端 | 个人创作者、内容分享者 | 通过网站提供地图风格化能力，拓展不同创作领域 |
| 轨迹场景 | 有轨迹表达与分享需求的用户 | 推动菠萝轨迹 App 原型，拓展 C 端使用场景 |

本人负责 B/C 端市场需求分析、盈利规划及上述产品方向的主要决策。项目处于早期商业化阶段，开展过一次小样本测试。

### 一项具体迭代

依据用户反馈调整风格模板的展示顺序，将更符合大众审美的模板前置。该调整着眼于用户初次浏览和选择模板的体验；尚无可公开的严格对照实验数据。

### 商业计划与路演

独立完成商业计划书、路演材料并承担路演；参与制定以中山大学资源支持大湾区发展、结合“太湖杯”相关资源探索长三角落地的发展安排。
